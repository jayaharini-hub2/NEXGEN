# NEXGEN — Next Generation Shopping Experience

A modern e-commerce web application designed to provide a seamless shopping experience and efficient business management.

## Project Overview

NEXGEN is a web-based e-commerce platform featuring a customer storefront and an administrative dashboard. It aims to combine a modern responsive interface with product management, inventory tracking, shopping cart operations, order management, and business analytics.

## Objectives

- Build a responsive and modern e-commerce website.
- Implement REST API-based communication using Axios.
- Use Firebase Firestore for data storage.
- Provide customer shopping and admin management interfaces.
- Maintain source code in GitHub and Azure Repos.
- Use Git branches and meaningful commits throughout development.

## API Architecture

The frontend communicates with backend services through HTTP requests using Axios. Data is exchanged in JSON format. Firestore is used for persistent storage.

## Version Control

The project is maintained using Git and hosted on:

- GitHub
- Azure DevOps Repos

Development branches are used to organize feature work, and completed changes are committed and pushed to both remote repositories.
